# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: open the
[Security tab](https://github.com/bioscan-ml/bioscan-browser/security) of this
repository and choose **Report a vulnerability**. Only the maintainers can see
the report.

Include what you found, how to reproduce it, and what you think the impact is.
We will acknowledge the report as soon as we can. This is a research project
maintained by a small team, so please allow some time for a full response.

## Scope

- The BIOSCAN Browser frontend in this repository.
- The deployed site at [browser.bioscan-ml.org](https://browser.bioscan-ml.org).

The backend APIs the browser talks to are maintained separately. If a report
concerns them, we will pass it along.

## Supported versions

Only the `main` branch and the currently deployed site are supported. There are
no versioned releases.
